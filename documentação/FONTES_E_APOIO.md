## Geração opcional

- [Preços e modelos do Gemini Developer API](https://ai.google.dev/gemini-api/docs/pricing)
- [Início rápido do Gemini API](https://ai.google.dev/gemini-api/docs/get-started)
- [Como proteger uma API key do Gemini](https://ai.google.dev/gemini-api/docs/api-key)
- [Termos e requisito de idade do Gemini API](https://ai.google.dev/gemini-api/terms)

Escolha apenas um modelo explicitamente marcado como gratuito no momento do uso. Não habilite cobrança para realizar a prova. Os termos atuais exigem idade mínima de 18 anos. No nível gratuito, dados enviados podem ser usados pelo provedor para melhorar produtos; envie somente a documentação pública da atividade. Quem não cumprir o requisito de idade ou não quiser criar uma conta deve usar o caminho local, sem qualquer perda de pontos.

## Assistentes de IA

ChatGPT, Codex, Gemini, Claude e outras ferramentas podem apoiar planejamento, implementação e diagnóstico. A disponibilidade e os limites gratuitos podem variar por conta. Nenhum assistente específico é obrigatório e nenhuma API da OpenAI é necessária para concluir o caminho mínimo.

Regra principal: use a ferramenta, teste o que ela produzir e esteja preparado para explicar as decisões adotadas.
